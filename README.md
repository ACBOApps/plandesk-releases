# PlanDesk — εκδόσεις

Δωρεάν εφαρμογή οργάνωσης εργασιών για γραφεία και ομάδες, που τρέχει στον δικό σας server.

**Λήψη:** δείτε την τελευταία έκδοση στο [Releases](https://github.com/ACBOApps/plandesk-releases/releases/latest) → `PlanDesk-Setup-x.y.z.exe`.

- Οι εγκαταστάσεις PlanDesk από την έκδοση 1.3.0 και μετά ελέγχουν μόνες τους για νέα έκδοση (Ρυθμίσεις → Server → Ενημερώσεις).
- Κάθε έκδοση φέρει ψηφιακή υπογραφή (Ed25519) και γίνεται δεκτή από την εφαρμογή μόνο αν η υπογραφή είναι έγκυρη.
- Η εφαρμογή παρέχεται δωρεάν, «ως έχει», χωρίς υποστήριξη. Αναλυτικές οδηγίες υπάρχουν μέσα στην εφαρμογή.

*Το Microsoft Planner είναι εμπορικό σήμα της Microsoft. Το PlanDesk είναι ανεξάρτητη εφαρμογή, χωρίς σχέση με τη Microsoft.*
